# 댄스스포츠 메트로놈

댄스스포츠 10종목 연습용 메트로놈. 아이폰에서 홈 화면에 추가하면 앱처럼 열리고 오프라인에서도 동작합니다.

- 10종목 **공식 템포 내장** (WDSF/WDC 경기 규정 기준) — 종목만 누르면 바로 시작
- **연습 단계에 맞춘 속도 조절** — 공식 대비 40~120%, 큰 ±버튼 · 프리셋 · 슬라이더 · 직접 입력
- **8박 예비박자** — 모든 재생이 예비박부터. 3박자 종목은 6박(2마디)으로 자동 보정
- **종목별 리듬 패턴** — 차차차 `원 투 쓰리 차 차`, 삼바 `1 a 2`, 자이브 `3a4`
- **음성 카운트** — 목소리 교체 가능, 앱에서 직접 녹음도 가능
- **내 음원 위에 박자세기** — 곡에 맞춰 탭하면 템포·다운비트를 잡아 카운트를 곡에 잠금
- **연습 기록** — 날짜별·종목별 시간, 연속 일수, 목표 (전부 폰 안에만 저장)

빌드 도구도 외부 라이브러리도 쓰지 않습니다. 정적 파일 그대로 배포하면 됩니다.

---

## 종목 템포

MPM = 마디/분(댄서 기준), BPM = 박/분(메트로놈 기준). **BPM = MPM × 박자수**

### 스탠다드
| 종목 | 박자 | 공식 MPM | 기본 BPM | 예비박 |
|---|---|---|---|---|
| 왈츠 | 3/4 | 28–30 | 87 | 6박 |
| 탱고 | 4/4 | 31–33 | 128 | 8박 |
| 비엔나 왈츠 | 3/4 | 58–60 | 177 | 6박 |
| 슬로우 폭스트롯 | 4/4 | 28–30 | 116 | 8박 |
| 퀵스텝 | 4/4 | 50–52 | 204 | 8박 |

### 라틴
| 종목 | 박자 | 공식 MPM | 기본 BPM | 예비박 |
|---|---|---|---|---|
| 삼바 | 2/4 | 50–52 | 102 | 8박 |
| 차차차 | 4/4 | 30–32 | 124 | 8박 |
| 룸바 | 4/4 | 25–27 | 104 | 8박 |
| 파소도블레 | 2/4 | 60–62 | 122 | 8박 |
| 자이브 | 4/4 | 42–44 | 172 | 8박 |

> **왈츠·비엔나왈츠가 6박인 이유** — 3박자에서 8박을 세면 본박이 마디 첫 박이 아니라
> 3박째에서 시작해 다운비트가 어긋납니다. 그래서 마디 배수인 6박(2마디)으로 맞춥니다.

## 아이폰에서 쓰기

1. Safari로 배포 주소를 엽니다
2. 공유 → **홈 화면에 추가**
3. 홈 화면 아이콘으로 실행 (주소창 없이 전체화면)

특정 종목만 따로 추가하고 싶으면 주소 뒤에 `#종목id`를 붙여서 추가하세요.
예: `.../#rumba` → 열면 바로 룸바 화면.
사용 가능한 id: `waltz tango vwaltz foxtrot quickstep samba chacha rumba paso jive`

### 알아둘 것

| 항목 | 내용 |
|---|---|
| **무음 모드** | 무음이면 소리가 나지 않습니다. 해제하거나 이어폰을 쓰세요. 웹에서는 우회할 방법이 없습니다. |
| **진동** | iOS는 웹 진동을 지원하지 않아 넣지 않았습니다. 대신 화면 비트 표시를 크게 했습니다. |
| **음원 파일** | 파일 앱에 있는 mp3·m4a·wav만 됩니다. 애플뮤직·스포티파이 스트리밍 곡은 DRM으로 열 수 없습니다. |
| **블루투스 이어폰** | 100~200ms 지연이 있어 화면과 소리가 어긋나 보일 수 있습니다. 정밀 연습은 유선이나 스피커를 권합니다. |
| **화면 꺼짐 방지** | iOS 16.4 이상에서 동작합니다. |

## 목소리 바꾸기

음절을 **의미 기반 고정 키 13개**로 다루고, 목소리 팩은 그 키들의 폴더일 뿐입니다.

```
1 2 3 4 5 6 7 8 cha a and slow quick
```

### 방법 1 — 앱에서 녹음 (가장 쉬움)
설정 → 목소리 → **내 목소리 녹음**. 화면에 음절이 하나씩 뜨고, 버튼을 누르고 있는 동안
녹음됩니다. 떼면 앞뒤 무음이 자동으로 잘리고 볼륨이 맞춰집니다. 13개에 2분쯤 걸립니다.
(마이크는 https 주소에서만 됩니다)

### 방법 2 — 파일로 넣기
설정 → 목소리 → 내 목소리 녹음 → **음성 파일 고르기**.
파일 이름을 키와 같게 하세요 (`1.wav`, `cha.wav`, `slow.wav` …).
일부만 넣어도 되고, 없는 음절은 기본 목소리로 자동으로 채워집니다.

### 방법 3 — 저장소에 팩 추가
1. `audio/voices/<팩id>/` 폴더를 만들고 13개 파일을 넣습니다
2. `js/voices.js`의 `BUILTIN` 배열에 한 줄 추가합니다
3. `sw.js`의 `VOICE_PACKS` 에 팩 id 를 추가하고 `CACHE` 버전을 올립니다

### 기본 목소리 다시 만들기
Windows 내장 음성(Heami/Zira)으로 생성합니다. 설치할 것 없습니다.

```powershell
powershell -ExecutionPolicy Bypass -File tools\gen-voice.ps1
```

발음할 텍스트는 `tools/voice-text.json`에 있습니다. 말이 빠르거나 느리면 그 파일의
`rate`(-10~10)를 조절하세요. 현재 값 6은 **한국어 최장 음절 293ms** 로,
가장 빠른 퀵스텝(204BPM, 한 박 294ms)에 겨우 들어가도록 맞춘 값입니다.
무음 트림과 노멀라이즈는 스크립트가 알아서 합니다.

## 음원에 박자세기 얹기

1. 플레이어 하단 **♪** → 폰에서 음원 고르기
2. **▶ 듣기**를 누르고, 곡의 박에 맞춰 탭 패드를 4번 이상 누릅니다
   — **첫 탭이 마디의 1박**이 되게 하세요
3. 템포와 첫 다운비트가 계산되면 미세조정(BPM ±0.1, 시작점 ±10ms)으로 맞춥니다
   - 템포가 절반/두 배로 잡혔으면 **÷2 / ×2** 버튼으로 한 번에 고칩니다
4. **이 곡으로 연습하기** → 예비박 뒤에 곡이 시작되고 카운트가 곡에 잠깁니다

곡과 카운트가 같은 오디오 시계에 예약되므로 곡이 끝날 때까지 어긋나지 않습니다.
(템포가 흔들리는 라이브 녹음은 예외 — 그때는 다시 정렬하세요)

음원은 어디로도 올라가지 않습니다. 폰 안에서만 디코딩되고 IndexedDB에 보관됩니다.

## 개발

빌드 스텝이 없습니다. `index.html`을 브라우저에서 바로 열면 동작합니다.
(단 `file://`에서는 음성 로딩·녹음·서비스워커가 막히므로, 그 셋은 배포한 https에서 확인하세요)

```
index.html            홈 · 플레이어 · 기록 · 시트 전체
styles.css
js/dances.js          10종목 데이터 + 리듬/카운트 패턴  ← 감이 다르면 여기만 고치면 됨
js/voices.js          목소리 팩 레지스트리 · 트림 · 저장
js/stats.js           연습 기록
js/audio.js           lookahead 스케줄러 · 클릭 합성 · 3버스 믹서
js/music.js           음원 로드 · 탭 정렬
js/app.js             화면과 상태
sw.js                 오프라인 캐시 (배포할 때 CACHE 버전을 올릴 것)
tools/gen-voice.ps1   기본 목소리 생성
tools/make-icons.ps1  아이콘 생성
tools/selftest.html   자가진단 — 브라우저로 열면 통과/실패가 표시됨
```

### 자가진단
`tools/selftest.html`을 브라우저로 열면 280여 개 검증이 실행됩니다.
템포 산술, 예비박 마디 정렬, 패턴 길이, 음절 키 존재 여부, 스케줄러 위치 진행을 확인합니다.

명령줄로 돌리려면:
```powershell
& "C:\Program Files (x86)\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu `
  --user-data-dir="$env:TEMP\dsm" --virtual-time-budget=4000 --dump-dom `
  "file:///$PWD/tools/selftest.html" | Select-String 'ALL PASS|FAIL '
```

### 타이밍이 왜 이렇게 되어 있나
`setInterval`로 직접 소리를 내면 브라우저 타이머 지터 때문에 박이 흔들립니다.
그래서 25ms마다 깨어나 **앞으로 120ms 안에 울릴 것을 `AudioContext.currentTime` 기준
절대시각으로 미리 예약**합니다. 실제 발음은 오디오 하드웨어 클럭이 담당하므로
화면이 버벅여도 박은 흔들리지 않습니다.

음성도 같은 방식으로 예약합니다. 브라우저 TTS를 쓰지 않는 이유가 이것입니다 —
TTS는 발음 시작 시각을 예약할 수 없어 빠른 템포에서 밀립니다.

## 배포 (GitHub Pages)

```bash
git init
git add -A
git commit -m "댄스스포츠 메트로놈"
```

github.com에서 빈 저장소를 만든 뒤 (README 체크 해제):

```bash
git remote add origin https://github.com/<계정>/dancesport-metronome.git
git branch -M main
git push -u origin main
```

저장소 **Settings → Pages → Source: `main` / `/ (root)`** → 저장.
1~2분 뒤 `https://<계정>.github.io/dancesport-metronome/` 에서 열립니다.

업데이트를 배포할 때는 `sw.js`의 `CACHE` 버전(`dsm-v1` → `dsm-v2`)을 올려야
기존 사용자에게 새 파일이 내려갑니다.
